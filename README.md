# Server-Infinite 1.2.0 for IBv13 (芽衣版本)

## 写在最前
基于 POC 的遗产进行改进，完善了主要的功能，但毕竟是带逆向性质的工作，与原生 Server 必然有差距，望理解

## 更新日志 (v1.2.0)

### Bugfix
1. 修复了玩家等级被限制在 200 的 bug
2. 移除了一些过期的功能，如战斗领航员、刷卡时胜率展示等
3. 统一了玩家名称与自定义 Title 的输入校验，现在不再禁止半角符号的输入，也不会再做长度校验
4. 修复了 Windows 10 的一些早期版本的兼容性问题
5. 修正了首页的一些过期信息
6. 计量表 UI 现在会正确显示名称，而不是形如 Gauge 1 的样式

### Feature
1. 完善了 tracker（加载界面时展示在名片下方的 1~3 个方框）相关的功能，现在 tracker 背景会正确随着玩家等级与机体熟练度的提升而变化，并且支持了两个副称号的设置
2. 新增了锁定图表样式的切换功能
3. 补齐了新增的各类素材，包括机体、贴纸、特效、机体 pose、称号、计量表等
4. 完善了默认贴纸设置，现在默认贴纸页面也可以设置展示觉醒立绘与副背景
5. 完善了新增机体与调整机体的下发，现在会正确展示 NEW 与 UPDATE 标签（自 v4 以来到 v13 的变更）
6. BGM Safe Mode 更名为 Game Commentary Mode（游戏实况模式），功能仍然不变

### Unhandled（目前明确未完善的）
1. Online 对战模式和大会模式仍未支持，本地应该用不到

### Tips（补充说明）
1. Game Commentary Mode（原 BGM Safe Mode），这个设置是为了直播/录制准备的（某些 BGM 可能存在版权问题？），开启这个选项会无视自定义 BGM 设置
2. 败方通讯固定发「ありがとうございます」，所以不要问结束时自定义通讯为什么不生效
3. 自动发送通讯的功能会无视掉战斗中的四方向自定义通讯设置，但是开幕和结束时的还是会生效
4. 训练场设置里关于耐久值有个“Revive”（战损）选项，不能在卡片设置里设置，只能在游戏内选取
5. 现代模式（Lite Type）是改不了键位的
6. 操作模式有“Normal Type (Default)”和“Normal Type (Custom)”之分，想使用自定义键位请选择后者
7. 机体贴纸设置里多了个 Sub Background 的设置，这个对应的是在开幕贴纸中显示驾驶员立绘时的那部分背景，但是美术素材复用了贴纸背景，所以卡片设置预览也直接复用了，实际效果看了就会明白的
8. 为了增加闲鱼骗子转卖的难度，现在启动时会有弹窗提示，五秒钟自动关闭，而且不会阻塞主程序启动，所以正常使用时可以直接无视，主要起提示之用（闲鱼骗子私募了）
9. 卡片设置网页若异常（持续白屏、旧版网页），请“清除该站点数据”（Chrome 或 Edge 浏览器 F12 进入开发者模式，右键左上角“刷新键”，选择“清空缓存并硬性重新加载”，其他浏览器自行查找方法）
10. Tracker 设置中的部分选项（如段位、OB 场数）缺乏数据，虽然可以显示，但是具体数值不准确，是正常现象
